# 小红书发布页（creator.xiaohongshu.com/publish/publish）

插件自带的初始笔记：给浏览器助手（b.agent）看的经验。页面以当时看到的为准；这个项目新学到的记在 user/notes/social/xhs.publish.md。

## 上传
- 素材由脚本传好再交给你：「上传图文」「上传视频」两个入口共用一个文件框，页面上还有看不见的同名标签副本，选错会把图传进视频框，所以不用你传。
- 视频传完前可以先填表；发布前调用 wait_upload 等它传完、处理完。

## 表单
- 标题：上面的输入框，提示「填写标题会有更多赞哦」之类，最多 20 字。直接 type。
- 正文：标题下面的编辑区（tiptap / ProseMirror，contenteditable，class `tiptap ProseMirror`），只能用 fill_body，不要自己打字。
- 话题：只有输入「#话题」后从候选里点选才变成话题块（`a.tiptap-topic`），只是文字的 #话题 不算；fill_body 会做。小红书没有的话题，候选第一项就是它，点了会新建（2026-10）。话题候选弹层还开着、挡住下面的东西就按 Escape。
- 第一次上传图片可能弹「图片可以编辑啦」的引导，点「我知道了」。
- 可见范围：在「更多设置」里，默认「公开可见」，控件本身看得见，直接点这个文字（不用先展开），下拉里选「仅自己可见」；任务要试发时选它。
- 地点、合集、内容类型声明、群聊等选填项不用动。

## 发布
- 「发布」按钮在 closed shadow root 里（`<xhs-publish-btn>`），你看不到也点不到：只能用 publish 工具，它核对后按文字点。
- 「暂存离开」不要点。
- 被拒（发布太频繁、违规词）时提示几秒就消失，publish 工具会从接口读出原话。
